### hibernate-plus 2.1.1 关键事实（反编译 jar 确认，非猜）
- 入口：`HibernatePlusService.createConfiguration(baseClass) → Configuration`，
  再 `HibernatePlusService.loadingService(configuration)` 才真正建 SessionFactory。
- `Configuration` 字段：`driveType / address / user / password / packageName / baseClass /
  extraEntity / classLoader / isAutoReconnect`；`classLoader` 默认取 `baseClass.classLoader`。
- `toProperties()` 把 URL 固定拼成 `getUrlPrefix(driveType) + address`。**H2 前缀硬编码
  `jdbc:h2:file:`**，所以只能文件库，塞不进 `mem:` 内存模式。其它前缀：sqlite `jdbc:sqlite:`、
  hsqldb `jdbc:hsqldb:file:`、mysql/mariadb/duckdb。
- 写死的属性：`hibernate.connection.provider_class=HikariCPConnectionProvider`、
  `hibernate.hbm2ddl.auto=update`、`hibernate-connection-autocommit=true`。H2 分支只补 `isolation=1`，
  不指定 dialect（自动探测）。
- 实体扫描：`scanEntity` 用 `org.reflections` 的 `ConfigurationBuilder.forPackage(packageName, cl)`
  + `Scanners.TypesAnnotated(Entity, Embeddable, MappedSuperclass)`。
  `packageName` 为空时回落 `baseClass.getPackageName()`。
- 工厂注册 key 是 **ClassLoader**：`HibernateFactory.Companion.initFactory(classLoader, factory)`；
  `getFactory()` 先按 **TCCL** 查，查不到时若 `factories.size == 1` 直接返回唯一那个（重要兜底）。
  `HibernateFactory` **没有 close()**，要关只能 `HibernateFactory.getSessionFactory().close()`。
- jar 内自带 `example/hibernate.properties`（MySQL 示例），无 META-INF/services。

- **logback-classic:1.5.16 离线不可用**：jar 在 files-2.1 里，但 descriptor 只存在于
  `metadata-2.107`，当前 Gradle 7.6.6 用的是 `metadata-2.101`，故 offline 报

  `useJUnitPlatform()`；所以生命周期用 `org.junit.BeforeClass/AfterClass` + `@JvmStatic`。
